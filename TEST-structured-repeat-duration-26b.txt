GiggleMe structured repeat/duration smoke test
================================================

Apply from the repository root:

  python3 apply-structured-repeat-duration.py
  git diff -- gigglebot.py

Then restart GiggleTest.

1. /giggle schedule should offer:
   repeat_unit: Minutes, Hours, Days, Weeks, Months
   repeat_every: integer
   duration_unit: Minutes, Hours, Days, Weeks, Months
   duration_for: integer

2. Test:

   repeat_every: 6
   duration_unit: Days
   duration_for: 3

3. Test Days, Weeks, and Months repeat intervals.

4. Validation:
   - unit without integer -> rejected
   - integer without unit -> rejected
   - zero/negative amount -> rejected
   - duration without repeat -> rejected

   repeat_unit: Remove repeat
   duration_unit: No duration limit

6. Confirm edit channel autocomplete still works.

7. Confirm existing stored daily / weekly / monthly repeats still reschedule normally.

gigglebot.py change after review/testing.
