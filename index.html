ACD Modmail - Server Members Intent Review

Evidence demonstrating why ACD Modmail requires Discord's Server Members privileged gateway intent.

Use case summary: ACD Modmail allows Discord users to contact the server moderation team by sending a direct message to the bot. When a user does so, Modmail must determine whether that Discord user is a member of the server and associate the DM sender with the corresponding server member. That member association is used when creating and managing the private staff-side Modmail thread.

1. A user contacts ACD Modmail by direct message

The user starts a Modmail conversation by sending a direct message to the ACD Modmail bot. Because the conversation begins in a DM rather than through a command inside the server, Modmail must independently determine the user's relationship to the server.

2. Modmail creates the private staff-side conversation

Modmail relays the user's message into the server's private moderation area and creates the staff-side conversation used to handle the request.

3. Modmail associates the DM sender with the corresponding server member

This is the portion of the workflow that requires the Server Members Intent. Modmail needs access to server-member information so it can accurately determine whether the DM sender is a member of the server and associate that Discord user with the correct member record used by the Modmail thread.

The member information shown to moderators provides the context needed to identify the person contacting the moderation team and handle the thread appropriately.

4. Moderators respond through the Modmail thread

Moderators work from the private staff-side thread while Modmail continues to associate the conversation with the correct Discord user and server member. Replies are relayed back to the user through the bot.

Why the Server Members Intent is required

The Server Members Intent is not used for presence tracking, advertising, or unrelated member monitoring. It is used so ACD Modmail can accurately check a user's server membership and associate a user who contacts the bot by DM with the corresponding server member needed by the Modmail workflow.

ACD Modmail is a self-hosted instance of the open-source Modmail project.
