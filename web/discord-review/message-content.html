GiggleMe and the Message Content Intent

GiggleMe requests Discord's Message Content Privileged Gateway Intent for its Auto Reply feature.

Why GiggleMe needs Message Content

Authorized GiggleMe users can configure an Auto Reply consisting of trigger text, reply text, and optional delivery behavior.

After an Auto Reply is configured, GiggleMe examines ordinary messages posted in that Discord server. When a message matches the configured trigger, GiggleMe sends the configured response.

This feature specifically reacts to normal user messages. The user sending the triggering message does not invoke a slash command or otherwise address GiggleMe.

Without access to Message Content, GiggleMe cannot determine whether an ordinary server message matches an Auto Reply trigger.

Slash commands are used for normal commands

GiggleMe's normal interactive command interface has been migrated to Discord slash commands.

Legacy ~giggle / ~g prefix-command compatibility may remain temporarily to help existing users migrate, but preserving prefix commands is not the reason GiggleMe requests Message Content access.

The privileged intent is requested because Auto Replies require access to the text of ordinary server messages.

How message content is handled

For Auto Replies, GiggleMe examines message text to determine whether it matches a configured trigger.

Ordinary server messages are not stored merely because GiggleMe examined them for an Auto Reply match.

If an Auto Reply itself is configured to quote, forward, delete, or otherwise act on a triggering message, GiggleMe may process the triggering content as necessary to perform that configured action.

Example

Trigger: hello-giggle
Reply: Hello from GiggleMe

A server member then sends a normal message:

hello-giggle

GiggleMe sees that the message matches the configured trigger and automatically replies:

Hello from GiggleMe

No slash command is involved in the triggering message.

Requested access

GiggleMe requests Message Content only because functionality that reacts to ordinary user-written messages requires access to the text of those messages.

GiggleMe does not request Message Content for analytics, advertising, profiling, or general message collection.
