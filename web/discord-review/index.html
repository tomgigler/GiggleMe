GiggleMe Privacy Policy

Effective date: August 15, 2026

GiggleMe is a Discord bot that provides scheduled messages, reusable templates, Auto Replies, VIP voice-channel announcements, and related server utilities.

This Privacy Policy explains what data GiggleMe processes, why it is used, how it is protected, and how users can request access to or deletion of stored data.

Information GiggleMe processes

GiggleMe may process and store the following information when needed to provide its features:

  • Discord user IDs and usernames
  • Discord server IDs and server names
  • Discord channel IDs and channel names
  • GiggleMe user preferences, including time zone and 12/24-hour time display
  • Scheduled-message content and related delivery settings
  • Reusable message templates
  • Message descriptions, repeat settings, and delivery metadata
  • Auto Reply trigger text, reply text, and configuration
  • VIP configuration used for voice-channel announcements

GiggleMe also processes Discord message content when Auto Replies are enabled. Message content is examined to determine whether it matches a trigger configured by an authorized GiggleMe user.

Ordinary server message content is not stored by GiggleMe merely because it was examined for an Auto Reply trigger.

GiggleMe may also process Discord guild-member and role information when resolving member or role placeholders in scheduled messages.

How information is used

GiggleMe uses this information only to provide and operate its features, including:

  • authorizing users to use GiggleMe in a server
  • scheduling, storing, editing, and delivering messages
  • storing and delivering reusable templates
  • detecting configured Auto Reply triggers and sending configured responses
  • resolving member and role placeholders at message-delivery time
  • operating VIP voice-channel announcements
  • storing user and server preferences
  • troubleshooting and maintaining the service

GiggleMe does not sell user data and does not use Discord data for advertising or user profiling.

Discord privileged data

GiggleMe requests access to two Discord Privileged Gateway Intents. The details and review evidence are documented separately:

  • Message Content is used for GiggleMe's Auto Reply feature.
  • Guild Members is used when resolving member or role placeholders, including role expansion.

GiggleMe does not request the Guild Presences privileged intent.

Data retention

GiggleMe retains stored configuration and user-created content while it is needed to provide the configured feature or until it is deleted through GiggleMe or by the service operator.

Before publishing: Document any specific automatic cleanup or retention periods that GiggleMe actually implements.

Data security

GiggleMe communicates with Discord over encrypted network connections.

Stored user-created message content is encrypted at rest in GiggleMe's database.

Administrative access to GiggleMe's systems and stored data is restricted to authorized operators.

Data sharing

GiggleMe does not sell or rent Discord user data.

Data is not shared with third parties except as needed to operate the service, protect the service, or comply with applicable legal obligations.
