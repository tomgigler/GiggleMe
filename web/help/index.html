Core workflow

Scheduling messages

Schedule one-time or repeating messages, select a destination channel, or build the message from a saved template.

/giggle schedule
  • Relative or absolute delivery times
  • Repeating schedules with an optional duration
  • Multiline content through the Discord editor
  • Optional delivery behavior such as pinning or publishing

Reusable content

Templates

Store reusable message content once, then use it when scheduling future messages.

/giggle template create

Existing templates can also be found and managed with the regular list, show, edit, and cancel commands.

Command reference

Slash commands at a glance

This is intentionally compact. Detailed explanations live with the feature they support.

/giggle helpOpen built-in GiggleMe help.
/giggle scheduleSchedule a message for delivery.
/giggle listList stored messages and related items.
/giggle showShow a stored item.
/giggle editEdit a stored GiggleMe item.
/giggle sendSend a scheduled message immediately.
/giggle cancelCancel a stored item.
/giggle edit-sentEdit a Discord message already sent by GiggleMe.
/giggle template createCreate a reusable template.
/giggle auto-reply createCreate an Auto Reply.
/giggle vip …List, add, or remove VIP voice announcements.
/giggle user …Grant or revoke GiggleMe user permission.
/giggle timezoneView or change your time zone.
/giggle time-formatView or change your time display format.
/giggle legacyUse legacy scheduling text or a Raw+ workflow.
/giggle testVerify slash-command plumbing.
